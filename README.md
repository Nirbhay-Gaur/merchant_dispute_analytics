# Merchant Dispute Analytics & Early-Warning Project

This is a portfolio/interview project using SYNTHETIC data.

## Business problem:

A card network wants to understand merchant dispute performance, identify operational drivers,
prioritize merchants that may need attention, and create an executive dashboard.

## Technology:

- Python / Pandas: exploratory analysis
- SQL / BigQuery: business metrics and insight generation
- PySpark: scalable transformation equivalent
- Power BI: executive dashboard
- GenAI: create an analyst briefing from validated metrics

## Core questions:

1. Are disputes increasing?
2. Which merchant segment drive the increase?
3. Which dispute reasons dominate?
4. Which merchants should be prioritized for intervention?
5. What business actions should leadership take?

## Key Findings:

1. From Jan to Dec total disputes have decreased from 1121 to 1082, showing -3.5% decrease. The steepest single-month jump was 9.0%, in 2025-03.

2. The top loss segment is Retail at $335,094 across 495 disputes.

3. Fraud is the dominating dispute reason.

4. Retail / E-commerce / Fraud combination count for 3.7% of total chargeback dollars across all combinations.

5. Target Fraud controls specifically within Retail and investigate the March 2025 spike specifically.
